# Development Roadmap

## Phase 1 — Foundation
Streamlit UI, Gemini, CrewAI, Manager Agent, Teacher Agent, session state.

## Phase 2 — Knowledge Grounding
PDF/DOCX/TXT/MD ingestion, chunking, Gemini embeddings, FAISS, hybrid retrieval, source panel.

## Phase 3 — Assessment
Practice generation, evaluator, mastery tracking, adaptive revision.

## Phase 4 — Research
Web search, source quality checks, research synthesis, citation display.

## Phase 5 — Learning Intelligence
Planner, study goals, concept graph, adaptive difficulty, revision recommendations.

## Phase 6 — Learning Modes
Socratic, case study, notes, flashcards, exam preparation.

## Phase 7 — Production
External persistent database, managed vector retrieval, authentication, analytics, evaluation datasets, rate-limit controls, monitoring, automated tests.
